# 快捷筛选 v2.2.0

本版新增**智能筛选（多字段搜索）**、**搜索框宽度可配置**与**快捷筛选拖拽排序**三项能力，全部由社区贡献者 **@hexiaomo** 提交（[PR #1](https://github.com/charce526/plugin-quick-filter/pull/1)）。

## 新增

### 1. 智能筛选（多字段搜索）

一个搜索框同时搜索多个文本字段。

- 目标字段限于文本接口：`input`、`textarea`、`email`、`phone`、`url`，支持多选，新建时默认选中第一个文本字段。
- 运算符只有「包含」`$includes` 与「等于」`$eq`；字段之间为「或」关系：
  `(字段A 包含 关键词) OR (字段B 包含 关键词)`
- 关键词仍需点击「搜索」或按 Enter 提交；提交空白内容会移除整个筛选组。
- V1：操作栏新增同级「智能筛选」菜单项。
- V2：「快捷筛选」子菜单首位新增「智能筛选」，复用同一个动作模型；基本设置的目标字段变为多选，值与运算符只提供「包含 / 等于」。

### 2. 搜索框宽度可配置

- 「显示设置 → 输入框宽度」，范围 **120–800 px**。
- 默认值：单字段筛选 **280 px**，智能筛选 **320 px**；替换原先硬编码的 280 px。
- 配置随页面 Schema / 模型 props 保存，不写入数据表。

### 3. 快捷筛选拖拽排序

- UI 配置模式下可直接拖动快捷筛选（含智能筛选）调整前后顺序，顺序随页面保存。
- V1：复用原生 Schema 拖拽（`SortableItem` + 原生工具栏），无需额外接线。
- V2：接入原生 FlowEngine 拖拽 —— 模型自带上报落点（`Droppable`），并通过 `flowSettings.addToolbarItem` 注册原生拖拽手柄。快捷筛选固定在操作栏左侧，而 NocoBase 默认只为右侧动作接线，插件补齐了缺的另一半，且不会与原生手柄重复。

## 修复

- 修复智能筛选占位符：V2 显示步骤改为按解析后的模式分支，「占位文字」可正确覆盖默认提示。
- 修复声明构建的 TypeScript 报错（TS2352 / TS2322），兼容混合外壳下的两套类型。
- 补充大量源码校验断言（智能筛选、宽度、拖拽手柄、V1/V2 菜单项等）。
